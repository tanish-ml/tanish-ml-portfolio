DEEP LEARNING ARCHITECTURE

A visual journey through a custom Multi-Layer Perceptron (MLP) built for edge-device anomaly detection. Scroll down to inspect the layers.

1 // INPUT LAYER

Sensors push raw telemetry data (784 dimensions) into the network. This layer normalizes the high-frequency noise and prepares the tensor for forward propagation.

2 // HIDDEN LAYERS

Two dense hidden layers with ReLU activation. The weights here were heavily quantized to INT8 to ensure real-time inference on edge microcontrollers without sacrificing accuracy.

3 // OUTPUT LAYER

The final Softmax layer condenses the learned features into a probability distribution, predicting the anomaly class instantly.
