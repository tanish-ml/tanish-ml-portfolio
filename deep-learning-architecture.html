FEED-FORWARD NETWORK

Welcome to the core of classical Deep Learning: The Feed-Forward Network (FFN).

Also known as a Multi-Layer Perceptron (MLP), this architecture is the foundation of modern AI. Scroll down to physically trace how data moves through the matrix.

1 // THE INPUT LAYER

Data enters the network here. Imagine a 28x28 pixel image being flattened into an array of 784 numbers. Each node represents one feature (e.g., the brightness of a single pixel).

X = [0.1, 0.9, ..., 0.4]
Shape: (batch_size, input_dim)

2 // WEIGHTS & BIASES

Every node connects to the next layer. These connections are 'Weights'. During training (Backpropagation), the network adjusts these weights to prioritize important signals and ignore noise.

Z = (W * X) + B

3 // HIDDEN LAYERS & ReLU

The nodes sum the weighted inputs. But to learn complex, real-world patterns, we must introduce chaos. We pass the sum through a non-linear Activation Function like ReLU, dropping negative values to zero.

A = max(0, Z)

4 // FORWARD PROPAGATION

Data flows strictly forward. Layer by layer, raw pixels are transformed into edges, edges into shapes, and shapes into high-level abstract concepts. This cascade is inference in real-time.

5 // OUTPUT & SOFTMAX

The final layer condenses the abstraction down to your target classes (e.g., "Cat" vs "Dog"). A Softmax function converts the raw scores into a clean probability distribution summing to 100%.

Prediction = argmax(Softmax(Output))

You have successfully traversed a forward pass. In Edge AI, we heavily quantize these weights to INT8 to run this entire massive calculation on microchips in milliseconds.
