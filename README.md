# 🌐 Neural Architecture | Tanish Mittal's Portfolio

Welcome to the source code for my interactive portfolio and digital arcade! This site is designed as a cyberpunk-themed "mainframe" that showcases my machine learning architectures, data science research, and personal projects.

**🔗 [Access the Live Mainframe Here](https://tanish-ml.github.io/tanish-ml-portfolio/)**

## 💻 Features

- **Cyberpunk Terminal Aesthetic:** Custom CRT monitor overlays, spectral ghost cursors, and data-decoding animations.
- **The Depth Chamber:** A 3D Z-axis flythrough that visualizes 16 of my GitHub repositories in physical space, terminating with a real-time ASCII-art render of my profile.
- **Arcade Vault:** A collection of standalone retro-style web games natively embedded into the site. These games were originally designed for a multi-stage digital escape room (`GIFT`) and have been rebuilt here as playable simulation modules.

## 🚀 Projects Showcased

The portfolio actively indexes and links to my machine learning, edge AI, and computer vision architectures, including:

- **TubeIntel** - AI YouTube Summarizer & Researcher
- **DocuMind** - Local Document Analyst Chatbot (RAG)
- **ResViT-Tiny** - Lightweight Hybrid Segmentation on Pascal VOC 2012
- **Quantum Circuit Extraction** - Extraction pipeline for Quantum Circuit Datasets
- ...and many more neural networks, regression models, and edge device algorithms.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript, Tailwind CSS
- **Graphics:** Custom 3D CSS matrix transforms, HTML5 Canvas API for real-time image-to-ASCII rendering
- **Arcade Engine:** Vite-based modular component system
